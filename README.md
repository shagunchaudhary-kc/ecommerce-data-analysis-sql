# Ecommerce SQL Analysis

This project performs SQL-based analysis on an ecommerce product dataset (fitness trackers / smartwatches) using MySQL.
The analysis focuses on pricing, discounts, ratings, battery life, and product features.

## Dataset
- Product-level ecommerce data
- Single table containing brand, model, pricing, ratings, battery life, display type, and strap material
- Total records: 554

## Tools Used
- MySQL
- Command Prompt (Windows)

## Key SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY with aggregate functions (COUNT, AVG)
- Data cleaning using string functions (REPLACE)
- Subqueries
- Views for clean and reusable analysis

## Analysis Performed
- Total product and brand distribution
- Average and brand-wise pricing analysis
- Discount amount and discount percentage calculation
- Rating-based product and brand analysis
- Battery life comparison across brands
- Feature analysis (display type, strap material)
- Identification of premium products (above average price)

## Project Files
- `ecommerce_analysis.sql` → All SQL queries used for analysis
- `screenshots/` → Query outputs captured from MySQL Command Prompt

## Outcome
This project demonstrates the ability to analyze structured ecommerce data using SQL and derive meaningful business insights suitable for internship-level data analysis roles.
